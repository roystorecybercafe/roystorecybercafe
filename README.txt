ROY STORE AND CYBER CAFE — WEBSITE STARTER
===========================================

Included:
- Responsive professional landing page
- Service cards and booking form
- Demo owner dashboard with Approve / Reject / Reset
- CSV export for demo bookings
- Basic privacy reminder for customers

IMPORTANT LIMITATION
This is a front-end demo. Bookings are stored in the browser's localStorage only. The owner dashboard will NOT receive requests submitted by customers on other devices. The demo PIN is visible in the source and is NOT secure authentication. Do not publish it as a real booking system until a secure backend/database and owner login are connected.

Before going live:
1. Confirm the shop's phone/WhatsApp number, full address, email (if any), opening hours, and exact services.
2. Connect a backend/database and secure owner login so customer bookings are shared across devices.
3. Set up booking notifications (for example, email/WhatsApp through an appropriate provider).
4. Add privacy policy and terms, and check local legal requirements.
5. Publish the finished site on a hosting provider and connect a domain if desired.

For a static preview:
- Open index.html in a modern browser.
